## 1. 콘텐츠 유형
SEO + 쇼핑커넥트 (상품 3개, 한 구간에 모음)

## 2. 주제
피부 장벽이 약해졌을 때 신호 + 장벽 크림 성분(세라마이드·판테놀·시카) 보는 법 + 성분별 3종 비교

## 3. 최종 제목
장벽 크림 추천 3종, 세라마이드·판테놀·시카 성분별 고르는 법 (35자)
부제: 피지오겔 · 라로슈포제 · 리얼베리어 비교

## 4. 키워드
- 키워드: 잠정(마피아넷 미확인). 네이버 자동완성 기준 수요만 확인. 마피아넷 결과에 따라 제목·첫 300자·태그만 바꾸면 되도록 작성.
- 메인 키워드: 장벽 크림 추천
- 서브 키워드: 피부장벽 크림, 겨울 크림 추천
- 관리 형태소 실제 횟수 (python 집계, 제목·[이미지]·쇼핑커넥트 ①②③·태그 줄 제외, 표·인용구·※ 포함):
  - 장벽 10회 (피부장벽 붙여쓰기 4회 포함)
  - 크림 14회 (제품명 포함)
  - 추천 3회
  - 참고: 피부장벽 4회 / 피부 장벽 4회 / 겨울 3회(겨울 크림 2회) / 세라마이드 6회 / 판테놀 7회 / 시카 5회
- 띄어쓰기 검색어 '장벽 크림 추천' 본문 통째 반복: 0회
- 첫 300자 안 검색어 단어: 장벽·크림·추천 모두 포함 (피부장벽·겨울도 포함)
- 기준 메모: 브리프는 '각 단어 3~7회', references/naver-top-ranking-rules.md 8절(2026-10-24 정정)은 제품명 단어 6~20회·수식 단어 3~12회·추천 1~6회. SKILL 원문(레퍼런스) 기준으로 맞췄다. 크림은 제품명 3개에 들어가 7회 이하로 줄이기 어렵다.

## 5. 전략 요약
- '장벽 크림 추천'을 제목 앞에 그대로 두고, 쉼표 뒤에 성분 세 갈래(세라마이드·판테놀·시카)를 부제로 넣어 10/23 건성 수분크림 글(제형 무게 기준)과 각도를 나눴다.
- 신호 체크 → 성분 보는 법(전성분 순서 규칙 포함) → 비교표 → 제품 3종 → 쇼핑 모음 → 주의점·바르는 순서 → 선택 가이드 순서의 비교형 구조.
- 제품은 성분 축이 하나씩 겹치지 않게 골랐다(세라마이드 피지오겔 / 판테놀·시카 라로슈포제 / 장벽 기능성 리얼베리어). 11/4 올영 블프 기간이라 행사 여부는 단정하지 않고 앱 공지 확인 안내만 넣었다.
