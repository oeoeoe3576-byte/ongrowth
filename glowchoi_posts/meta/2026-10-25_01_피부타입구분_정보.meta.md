# 2026-10-25_01_피부타입구분_정보 메타

## 1. 콘텐츠 유형
SEO 검색형 / 순수 정보형 (쇼핑커넥트 없음)

## 2. 주제
수부지·복합성·건성·지성 구분법 자가 체크 + 타입별 기초·베이스 팁

## 3. 최종 제목
수부지 복합성 차이, 세안 후 자가 체크로 구분하는 피부 타입 4가지 (38자)

## 4. 전략 요약
- '차이' 검색어라 정의 → 헷갈리는 두 타입 핵심 구분 → 세안 후 자가 체크 표 → 타입별 기초/베이스 팁 순서의 방법·비교형 구조.
- 비교 정보가 많아 표 1개 사용, 사진은 방법형 기준 8장.
- 의학적 단정을 피하고 "경향", "가까운 편" 표현 사용, 트러블 지속 시 전문의 상담 안내.
- 기존 '세미매트 쿠션 추천'(수부지 베이스) 글과 내부 연결 가능.

## 5. 이미지 계획 (8장)
- ① 도입 / 세안 직후 거울 앞에서 부위별 유분 살피는 모습 / 직접촬영 또는 AI(얼굴 비중 낮게)
- ② 개념 섹션 끝 / 얼굴 T존·U존 구역 표시 일러스트 / 직접 제작 그래픽
- ③ 자가 체크 표 아래 / 세안 후 맨얼굴 T존과 볼 비교 클로즈업 / 직접촬영
- ④ 기름종이 문단 아래 / 이마·코·볼 기름종이 3장 비교 / 직접촬영
- ⑤ 기초 팁 끝 / 젤·로션·크림 제형 손등 비교 / 직접촬영
- ⑥ 베이스 팁 끝 / 광·세미매트·매트 피부 표현 비교 / 직접촬영 또는 AI
- ⑦ 베이스 팁 끝 / T존에만 파우더 누르는 과정 / 직접촬영
- ⑧ 마지막 / 4가지 피부 타입 특징 요약 카드 / 직접 제작 그래픽
