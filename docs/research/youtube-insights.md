# 유튜브 여행 정보 영상 — 읽은 패턴 (2026-10-23, 1차)

대상: 여행·코스·맛집 등 제목 키워드로 거른 정보형 영상 16,723개 (브이로그·광고성 제외, 채널당 15편 이상). 점수 = 조회수 ÷ 채널 평소 조회수.
스크립트: `tools/research/yt_patterns.py` (DB: `data/research/youtube_travel.db`). 제목·길이·챕터 기반이라 화면·자막은 못 본 결과.

## 길이 (점수 중앙값 / 상위10% 문턱)
- 60초 이하 1.00 / 5.2 · 1~3분 0.97 / 4.5 · 3~8분 0.75 / 6.9 · 8~15분 1.29 / 9.9 · 15분+ 1.46 / 9.4
- 쇼츠는 평균은 평범해도 터지면 수백만 (히트가 큼). 길이 자체보다 "내용 밀도"가 갈림.

## 상위 영상 제목에 많이 나오는 말 (상위 3배+ vs 평범)
가이드 ×4.7 · 6곳/5곳/3곳/10곳(숫자+곳) ×2~4 · 완벽/총정리 ×2.4~3.5 · Best/베스트 ×3 · "이대로만" ×3.2 · 경비 ×2.6 · 2박3일/3박/1박2일 ×2~3 · 여행코스·일정 ×2.1~2.5 · 연도(2026년) ×2.8 · 월(10월 등) ×2 · "놓치면" ×2.2 · 단풍/온천 같은 시즌 소재 ×2.5

## 상위 쇼츠(60초 이하) 공통점
- 제목 안에 결론이 숫자로 있음: "총 경비 3만원, 연차없이 익산 당일치기 코스", "1박2일 얼마 썼을까?", "단풍 명소 BEST 5", "전주맛집 8곳"
- 감정 훅 + 구체 지역: "한국에 이런 곳이?", "죽기 전에 꼭 가봐야 할", "서울에서 한 시간!"
- 해시태그·이모지 많은 건 많음, 단 이모지 유무 자체의 차이는 ×1.01 (효과 없음)
- 고정댓글·캡션에 상세 정보를 넘기는 구조("자세한 내용은 캡션 참고", "할인꿀팁은 고정댓글")가 반복

## 상위 중·장편 공통점
- "X 총정리/가이드/완벽정리" + 지역 + 연도: 검색형. 챕터를 붙인 영상은 점수 1.45 (없는 영상 0.99)
- "모든 ○○ 여행지 40초 요약" 같은 압축형, "비교(vs)", "최악 vs 최고", "손해·주의"형이 장편에서 강함
- 비용(경비·원 단위)이 제목에 있는 영상이 반복해서 상위

## 우리 계정에 주는 시사점 (가설, 검증 필요)
1. 제목/첫 화면에 "숫자 + 곳 + 비용/일정"을 한 줄로 (예: "1박2일 ○○ 총경비 ○만원 코스")
2. 15초 감성 영상보다 "정보 밀도 높은 30~60초 + 상세는 캡션/고정댓글" 구조
3. 시즌 소재(단풍·온천)와 연도·월 표기는 검색 수요와 맞음 (벚꽃·전시팝업은 낮음)
4. 같은 포맷을 3~5편 반복해 우리 지표(평균 시청 비율·저장·공유)로 검증 후 확정

# 2차: 구조·업로드·썸네일 (같은 16,723개 기준, 스크립트 `tools/research/yt_structure.py`)

## 효과가 있었던 것 (점수 중앙값 / 상위10% 문턱)
- 제목이 **숫자로 시작**: 1.25 / 10.1 (글자로 시작 1.03 / 5.9) — 가장 큰 차이
- 제목에 **비용**(원·경비·비용): 1.20 / 9.2 (없음 1.03 / 6.3)
- 제목에 **일정**(1박2일·당일·N시간): 1.23 / 7.8 (없음 1.02)
- **감정 훅**(이런 곳·진짜·후회·꼭·비밀·현실): 1.10 / 9.8 → 중앙값 차이는 작지만 터질 확률이 큼
- **댓글/캡션/고정댓글 유도 문구**: 1.16 / 9.5

## 효과가 없거나 반대였던 것
- 제목 해시태그: 0개가 가장 좋음(1.09 / 7.6), 1~5개는 모두 ~1.0 — 해시태그 많을수록 나쁨
- 이모지로 시작, 지역명 포함 여부, 요일·업로드 시각: 거의 차이 없음(요일 1.00~1.10, 시각 0.97~1.13). 시간대 최적화에 시간 쓸 필요 없음
- 쇼츠 길이: 15초 이하(1.03 / 상위10% 6.8)가 오히려 약간 유리, 31~45초는 약함. 길이보다 내용이 갈림
- 좋아요율은 점수와 무관(0.7~0.9%), 댓글율은 오히려 낮은 영상이 높음 → 반응률로는 구조를 못 가림

## 상위 장편의 챕터 뼈대 (반복되는 구조)
1. 인트로(10~60초)에서 결론/약속 → 2. 도시·코스를 번호 없이 짧은 단위(30~60초)로 압축 나열 → 3. 마지막에 총평/추천 성향
- "모든 ○○ 여행지 40초 요약": 인트로 + 지역 15~20개를 40~60초씩 (동남아 730배, 유럽 235배, 일본 210배)
- "최악 TOP3 vs 최고 TOP3": 2막 구조(대비)
- "필수여행지 → 선택여행지 → 추천 성향" (LA 504배): 우선순위 분류
- 맛집 66곳처럼 개수가 많아도 지역별 챕터 + 가게별 30~40초로 쪼갬

## 썸네일 (상위 12개 vs 중하위 12개 직접 비교)
- 상위: 글자 2줄, 크고 굵게, 흰·노랑·빨강 강조색 → "○○ 꼭 가봐야 하는 이유", "모든 ○○ 50초 요약", "1~2만원대 갓성비 66", "최악 vs 최고 TOP3"처럼 **약속(이유·요약·숫자)이 한눈에**. 배경은 지도·단일 풍경·단일 인물.
- 중하위: 사진이 복잡하고 글자가 작거나 없음, 얼굴·셀카 위주, 약속이 안 보임.
- 공통: 썸네일 문구와 제목 문구가 **같은 약속**을 반복하지 않고 서로 보완 (썸네일 = 이유/감정, 제목 = 숫자·범위).

## 한계
- 썸네일은 시각 비교 12:12 표본, 통계가 아님. 영상 본문·자막·BGM은 못 봄.
- '중하위'는 조회 2~6만대 장편 표본이라 "진짜 망한 영상"은 아님.
