글로우 초이 버전은 여기에 **선택 가이드 카드**를 더하고, 아래 규칙으로 다듬었다.
- 어두운 그라데이션 띠 대신 단색 띠를 쓴다 (PART 48).
- 한 글에 포인트 컬러 한 계열만 쓴다 (PART 47).
- 인물 얼굴은 AI로 만들지 않는다. 표지에는 제품 라인업이나 텍스처 사진을 쓴다 (PART 32).
- 모든 카드에 같은 프레임(포인트색 점선 테두리 + 오른쪽 아래 'GLOW CHOI')을 넣어 계정 통일감을 준다.


## 3. 이미지 구성 공식 (한 편 기준)

**검색형(SEO) 7~9장**
1. 표지 카드 (cover)
2. 포토 캡션 카드 1장 (caption): 텍스처나 사용 장면 사진에 핵심 한 줄
3. 정보 시트 또는 단계 카드 1장 (sheet / steps)
4. 제품 카드 × 상품 수 (product)
5. 루틴·사용법 단계 카드 (steps)
6. 선택 가이드 카드 (guide)
7. (선택) 실사 사진 1~2장: 직접 찍은 사진이 있을 때 우선 사용

**홈판형 5~6장**
표지 → 포토 캡션 → 단계/비교 → 제품 카드(또는 쇼핑 카드) → 선택 가이드

실사 사진과 정보 카드 비율은 대략 반반을 목표로 한다.
사용자가 직접 찍은 사진이 있으면 포토 캡션 카드와 실사 자리에 먼저 쓴다.


## 4. 본문 서식 (네이버 에디터 설정)

| 요소 | 설정 |
|---|---|
| 정렬 | 전체 가운데 정렬 |
| 글꼴 | 나눔스퀘어 또는 나눔바른고딕 (한 글 안에서 하나로 통일) |
| 본문 크기 | 16 |
| 이미지 아래 설명 | 13, 회색 |
| 소제목 | 인용구 **라인형**, 글자 19, 굵게, 포인트 진한색 |
| 구분선 | line1 (얇은 실선), 큰 단락 전환 때만 |
| 강조 문장 | 굵게 + 포인트 진한색, 한 단락에 1곳 이하 |
| 형광펜 | 포인트 연한색, 글 전체에 2~3곳 이하 |
| 강조 박스 | 1칸 표, 배경 = 포인트 연한색, 테두리 = 포인트 진한색 점선, 글 전체에 1곳 |
| 표 | 머리 행 배경 = 포인트 연한색, 나머지 흰색 |
| 스티커 | 쓰지 않거나 1개 이하 (에디토리얼 톤 유지) |
| 쇼핑커넥트 | 상품 3개는 한 구간에 모음 (PART 57-5) |

## 6. 카드 만드는 법

```python
import sys; sys.path.insert(0, "tools/glowchoi")
import cards as C
p = C.PALETTES["apricot"]
C.cover(photo, "GLOW CHOI 뷰티노트", "가을 기미·잡티,\n미백 앰플 어떻게 고를까?", "성분별로 고르는 법과 추천 3종", p, contain=True).save("01_cover.jpg")
C.caption(photo, "CHECK", "'미백 기능성' 표시부터 확인하세요", p, "식약처 심사·보고를 거친 제품만 표시할 수 있어요")
C.sheet("POINT", "성분별로 이렇게 달라요", "Brightening Ingredients", [("비타민C", ["…", "…"]), ...], p)
C.product(cutout_png, "#비타민C #나이아신아마이드", "제품명", "한 줄 특징", p, badge="01")
C.steps("아침 루틴", [("STEP 1", "토너 다음\n앰플을 얇게"), ...], p, note="…")
C.guide("그래서 뭘 고를까?", [("고민", "추천"), ...], p, "마무리 한 줄")
```

- 크기: 1080 × 1080 (네이버 모바일에서 가장 안정적인 정사각)
- 제품 누끼: 공식몰 제품 사진을 rembg로 배경 제거해서 쓴다. 인물·연예인이 나온 공식 사진은 쓰지 않는다.
- 카드에 들어가는 문구는 원고 내용과 같아야 하며, 원고에 없는 효능·수치를 카드에만 쓰지 않는다.
