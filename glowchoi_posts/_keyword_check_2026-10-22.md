# 10/23~10/29 원고 키워드 검색 수요 확인 (2026-10-22)

방법: 네이버 자동완성(ac.search.naver.com)에서 앞부분만 입력했을 때 그 키워드가 뜨는지, 몇 번째인지 확인.
자동완성은 많이 검색되는 순서로 뜨므로 "뜬다 = 검색 수요 있음, 위일수록 많음"으로 본다.
절대 검색량(월 조회수)은 네이버 검색광고 API 키가 있어야 확인 가능.

## 검색 수요 확인됨 (유지)
| 키워드 | 자동완성 결과 |
|---|---|
| 핸드크림 추천 | '핸드크림' 입력 시 2위 |
| 메이크업 픽서 추천 | '메이크업 픽서' 입력 시 2위 |
| 가을 블러셔 추천 | '가을 블러셔' 입력 시 2위, '블러셔 추천'에서도 노출 |
| 건성 바디로션 추천 | '건성 바디로션' 입력 시 2위 |
| 퍼스널컬러 자가진단 | '퍼스널컬러' 입력 시 4위, 하위 검색어 10개 |
| 가을 메이크업 트렌드 | '가을 메이크업' 입력 시 5위 |
| 퍼플 니트 코디 | '퍼플 니트' 입력 시 5위 |
| 쿠션 호수 고르는 법 | '쿠션 호수 고르는' 1위 ('쿠션 호수 비교'가 더 큼) |
| 할로윈 메이크업 | 하위 검색어 10개 (샵·예약·분장 등 서비스 의도 섞임) |
| 건성 수분크림 추천 | '수분크림 추천' 입력 시 '건성수분크림추천' 노출 (약함) |

## 검색 수요 거의 없음 → 교체 제안
| 현재 키워드 | 근거 | 교체 키워드 |
|---|---|---|
| 블루그레이 섀도 | 자동완성 없음 | 쿨톤 섀도우 (1위, 팔레트·추천 하위어 있음) |
| 각질 립밤 추천 | 자동완성 없음 | 립밤 추천 ('립밤' 2위) + 입술 각질 각도 |
| 수부지 복합성 차이 | 정확히는 없음 | 지성 건성 복합성 구분 ('피부 지성 건성 구분' 1위) |
| 브라운 아이 메이크업 | 끝까지 쳐야만 뜸 | 가을 아이 메이크업 ('가을 아이메이크업하는법') |
| 브라운 섀도 팔레트 추천 | 자동완성 없음 | 가을 섀도우 팔레트 추천 (노출) |
| 소프트 그런지 메이크업 | '뜻'만 노출 | 스모키 메이크업 하는 법 (하위어 10개) |

표기 주의: 사람들은 '섀도'보다 '섀도우'로 검색함.
