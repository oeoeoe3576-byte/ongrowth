# 글로우 초이 블로그 디자인 템플릿

사용자가 원래 쓰던 '블로그 서식 복사함'(퍼스널컬러 시리즈) 디자인을 그대로 따른다.
2026-10-23에 만든 흰 배경 + 점선 프레임 템플릿은 반려됐으므로 쓰지 않는다.


## 1. 이미지 카드 (1000 × 1000, `tools/glowchoi/cards.py`)

| 카드 | 함수 | 구성 |
|---|---|---|
| 썸네일(기본) | `thumb` | 연한 배경 + 필기체 영문 + 굵은 한글 제목(Black Han Sans) + 포인트색 알약 부제 + 아래 빛나는 타원 위 제품 누끼 라인업 |
| 퍼스널컬러 표지 | `cover` | **퍼스널컬러 시리즈 전용.** 다른 주제 썸네일로 쓰지 않는다. 위아래 컬러칩 띠 7색 + 필기체 영문(Parisienne) + 아주 굵은 한글 제목(Black Han Sans, 진한 브라운) + 얇은 영문 부제 + 포인트색 한 줄 |
| 포인트 목록 | `point_list` | 컬러칩 띠 + 필기체 영문 + 굵은 제목 + 번호 동그라미 목록 (가장 긴 줄 기준 가운데 정렬) |
| 한눈에 보기 | `overview` | 연한 배경 + 흰 둥근 패널 + 항목명(포인트색) / 설명 / 해시태그 알약 |
| 제품 | `product` | 연한 배경 + 왼쪽 위 세로선과 '브랜드 / 제품명 / 카테고리' + 가운데 빛나는 흰 원 위 누끼 + 아래 굵은 #키워드 |
| 팔레트 | `palette` | 둥근 컬러칩 + 이름 + 색상코드 |

배경은 순백만 쓰지 않는다. 제품·한눈에 보기 카드는 테마의 연한 배경(tint)을 쓴다.

## 3. 이미지 구성 (검색형 기준 8장 안팎)

썸네일(thumb) → 체크 포인트 → 한눈에 보기 → 제품 카드 × 상품 수 → 루틴 포인트 → 선택 가이드(my pick).
직접 찍은 실사 사진이 있으면 제품 카드 앞뒤에 넣는다.

## 4. 본문 서식 (`tools/glowchoi/format_html.py`)

| 요소 | 서식 |
|---|---|
| 첫 줄(제목) | 가운데, 24px 굵게, 포인트색 |
| 본문 | 가운데, 15px, #333333 |
| 소제목([인용구]) | 왼쪽, 19px 굵게, #333333 |
| 강조([강조 박스], → 추천 줄) | 가운데, 나눔손글씨 펜 19px, 포인트색 |
| 제품명(01. …) | 굵게 + 포인트색 #번호 |
| 순서 목록(1. …) | ✅ + 굵게 |
| 단락 사이 | 빈 줄 `<p><br></p>` |

```
python3 tools/glowchoi/format_html.py 원고.md 이미지폴더 "#A07B5E" 출력.html
```
출력 페이지의 '전체 복사'를 눌러 네이버 글쓰기에 붙여넣는다.

## 5. 누끼

- 공식몰(Shopify `.json`) 제품 단독 사진을 rembg로 배경 제거한다.
- 세트 배너, 모델 사진, 다른 제품이 겹친 사진은 쓰지 않는다.
- 카드 문구는 원고 내용과 같아야 한다. 원고에 없는 효능·수치를 카드에만 쓰지 않는다.
