# 뷰티레터 카드뉴스 디자인 양식

**컨셉: 뷰티레터 — 매주 받아보는 뷰티 편지.** 에디터가 이번 주 뷰티 소식을 골라 편지처럼 정리해 보내주는 뉴스형 매거진입니다.

인스타그램 캐러셀(1080×1350, 4:5)과 블로그 본문 이미지에 같이 쓰는 양식입니다.
`slides.html`이 원본이고, `node design/beauty_news/render.mjs`를 실행하면 `preview/*.png`가 만들어집니다.

## 레터 규칙
- 마크: `BEAUTY letter` (BEAUTY 대문자 + letter 소문자 이탤릭). 상단에만 넣고 하단에는 넣지 않습니다.
- 호수(No.01 등)는 넣지 않습니다. 순서가 꼬일 수 있어서 아예 빼기로 했어요 (2026-10-01).
- 표지에는 상단 로고 + 카테고리 라벨 + 제목(+서브)만 넣습니다. 하단 바(로고·"옆으로 넘겨보기")와 사진 출처·AI 표기는 표지에 넣지 않습니다. 출처는 `sources.md`, AI 표기는 캡션에 적습니다.
- 카테고리: 표지 헤드라인 위 라벨 앞에 붙입니다. `New Letter`(신상) / `Issue Letter`(이슈) / `Color Letter`(컬러) / `Sale Letter`(세일).
- 핸들: `@from.beautyletter`

## 문구 톤
- 카피는 친구에게 쓰는 편지처럼 다정하게 씁니다. 예: "이번 주엔 탱글한 틴트 소식을 담아 왔어요"
- 정보는 사실과 출처 중심으로 씁니다. 가격·컬러·웜쿨 같은 정보는 공식 출처가 있는 것만 씁니다.
- 직접 써보지 않은 제품의 사용감은 "~준대요", "~라고 해요"처럼 전달형으로 씁니다.
- "가장 많이 물어본" 같은 표현은 실제로 그런 반응이 있을 때만 씁니다.

## 톤
- 정보는 정확하게, 분위기는 부드럽게.
- 배경은 크림이나 블러시 톤을 쓰고, 포인트 컬러는 로즈 하나만 씁니다. 형광 핑크나 원색은 쓰지 않습니다.
- 영문 장식(브랜드명, 숫자, Editor's Pick)은 세리프체(Cormorant), 한글은 전부 Pretendard로 씁니다.

## 타이포 스케일
- 표지 헤드라인: 104–112px / ExtraBold / 자간 -3px. 한 줄에 7자 안쪽, 최대 3줄까지 씁니다.
- 슬라이드 제목: 70–72px / ExtraBold. 최대 2줄까지 씁니다.
- 본문: 30–32px / Medium / 행간 1.6. 3줄 안쪽으로 씁니다.
- 키커(섹션 라벨): 24–28px / Bold / 로즈색 + 앞에 짧은 선.
- 키워드 강조는 한 장에 한 번만 합니다(`<em>`, `.hl`, `.mark`).

## 슬라이드 유형 (7종)
| 파일 | 용도 | 넣을 것 |
|---|---|---|
| 01_cover_photo | 제품·인물 사진 표지 | 사진 1장, 카테고리 라벨, 헤드라인, 호수, #광고(협찬일 때만) |
| 02_cover_type | 사진 없는 이슈·정리형 표지 | 큰 숫자/연도, 카테고리 라벨, 헤드라인, 서브 2줄 |
| 03_product | 제품 소개 | 제품 누끼 PNG, 가격 스티커, 소개 박스 |
| 04_spec_shade | 컬러칩과 스펙 | 호수별 HEX 또는 발색 사진, 가격·컬러·추천 표 |
| 05_point | 키워드나 포인트 | 무드 사진, 번호, 키워드, 추천 제품, 본문 |
| 06_review | 에디터 후기 | 직접 써봤을 때만. 항목별 점수, 좋았던 점·아쉬운 점, 한줄평 |
| 07_summary | 오늘의 요약 (2026-10-01부터 기본 제외, 필요할 때만) | What · Point · Who · Price 네 줄, 해시태그 칩 |
| 08_ps | **P.S. (매 레터 마지막 장 고정)** | 에디터 한 줄 팁이나 퍼스널컬러 코멘트, "다음 레터에서 만나요", 저장·팔로우, 이미지 출처 |
| opt_A_tone_meter | 선택 장: 톤 온도계 | 컬러가 여러 개이고 공식 컬러차트가 있을 때만. 출처 표기 필수 |
| opt_B_personal_color | 선택 장: 퍼스널컬러 매칭 | 컬러 정보가 중요한 레터에만. 에디터 추천임을 표기 |

고정 구조는 **표지(01 또는 02) → … → P.S.(08)** 입니다. 오늘의 요약 장, '한 장으로 정리' 같은 앞 내용을 다시 모은 장은 넣지 않고(2026-10-01·10-02 결정), 요약은 캡션 앞부분에 짧게 씁니다. 핵심 정보 장은 표지 바로 다음(2번째 장)에 둡니다. **전체는 표지·P.S. 포함 5장 이상**(본문 3장 이상, 2026-10-01 사용자 결정)으로 맞춥니다.
선택 장 A·B는 컬러 정보가 중요한 레터에만, 둘 중 어울리는 하나를 고릅니다. 공식 컬러차트를 근거로 쓰면 출처를 꼭 적습니다.

| 카테고리 | 추천 조합 |
|---|---|
| New Letter (신상) | 01 → 03 → 04 → (A) → 05 → 07 → 08 |
| Color Letter (컬러) | 01 → 04 ×N → A 또는 B → 07 → 08 |
| Issue Letter (이슈·트렌드) | 02 → 05 ×N → 07 → 08 |
| Sale Letter (세일) | 02 → 03 ×N → 07 → 08 |
| 직접 써본 리뷰 | 01 → 03 → 04 → 06 → 07 → 08 |

같은 유형을 여러 장 써도 됩니다(×N). 주제에 맞지 않는 장은 억지로 채우지 말고 빼세요.

## 발행 시간 규칙 (2026-10-07 사용자 지시)
- 정해진 시간(08:30/20:30)이 지난 레터는 **늦게라도 바로 올리지 않는다.** 다음 빈 시간으로 미뤄서 그때 올린다.
- **한 번에 하나만** 올린다. 밀린 레터가 여러 개여도 시간마다 1개씩.
- **여러 개를 한 번에 승인해도 한 번에 올리라는 뜻이 아니다.** 승인한 것들은 시간마다 1개씩, 정해진 순서대로 올린다.
- 밀리면 뒤 일정은 **반드시 한 칸씩** 미룬다(빈 시간을 건너뛰거나 두 개를 같은 시간에 넣지 않기).
- **승인이 나면 말하지 않아도 바로 다음 레터 시안을 만들어 보낸다.**
- 승인 범위("나머지", "이거 빼고" 등)가 애매하면 레터 제목을 하나씩 짚어 확인한 뒤 승인 처리한다.
- 올라간 게시물은 **삭제하지 않는다**(인스타 노출에 불리). 내려야 하면 앱에서 **보관** 처리한다(API로는 보관이 안 됨 → 사용자에게 요청).
- 레터가 밀리면 뒤 일정도 **계속 한 칸씩 미룬다**(캘린더 날짜를 같이 옮김).
- `npm run beauty:due`가 이 규칙대로 동작한다(발행 시각 60분이 지나면 자동으로 다음 빈 시간으로 미루고, 실행 1번에 최대 1개 발행).

## 기본 제작 방식 (2026-10-06 사용자 확정: "앞으로도 이런 식으로")
매 레터를 아래 방식으로 만든다. 이 기본 세트는 **매번 따로 허락받지 않고 만들어도 된다** (사용자 상시 승인). 이 밖의 추가·재생성은 기존처럼 먼저 묻는다.
- **표지 = AI 인물 클로즈업 1장** (Topview, Nano Banana 2 Lite, 4:5, 1K, 0.3크레딧)
  - 예쁜 20대 한국 여성, 얼굴이 크게 보이게 클로즈업. 35mm 필름 느낌, 자연광, 피부결이 살아 있는 사진(AI 티 줄이기: "real skin texture, not airbrushed, candid").
  - 주제 메이크업·헤어가 얼굴에서 보여야 한다. 웃음보다 주제에 맞는 표정.
  - 제목이 입술·눈을 가리지 않게 얼굴이 화면 위쪽 절반에 오도록 잘라서 쓴다(필요하면 PIL로 크롭·확대). P.S. 배경은 표지 이미지가 자동으로 깔린다.
  - 헤어·메이크업처럼 사람이 필요 없는 주제(제품·네일 등)는 기존 규칙(풍경+누끼, 무료 사진)도 가능.
- **본문 예시 그림 = 수채화 일러스트, 페이지당 1장** (Topview, Nano Banana 2 Lite, 16:9, 1K, 0.3크레딧)
  - 프롬프트 앞부분 고정: "Delicate watercolor and colored-pencil beauty illustration, soft fashion-magazine editorial style, warm cream paper background, muted dusty pink and beige palette, clean composition, evenly spaced panels." + 비교/단계 내용(왼쪽·가운데·오른쪽) + "Absolutely no text, no letters, no numbers, no labels."
  - 그림 안에는 글자를 넣지 않고, 아래에 HTML 라벨을 붙인다: `<div class="vis illu"><img src="img/illu_이름.jpg"/><div class="lb"><span>…</span><span class="on">…</span></div></div>` (CSS는 기존 레터 `extra.css`의 `.card .vis.illu` 블록 복사). 이미지는 위아래 7~9% 잘라서 저장.
  - SVG·CSS로 직접 그린 얼굴·입술·머리 그림은 쓰지 않는다 ("너무 구림").
- Topview 동시 작업 한도가 있어 한 번에 4장 정도씩 나눠 제출한다. 여분 생성 금지(페이지당 1장).
- 생성 이미지는 `sources.md`에 "Topview AI 생성" 으로 적는다.

## 사진 규칙
- `[data-slot="photo"]` 자리에 `<img>`를 넣어 교체합니다. 지금 보이는 그라데이션은 자리 표시용입니다.
- 표지 사진은 아래쪽 40%가 비교적 단순한 컷을 고릅니다. 텍스트가 그 위에 올라갑니다.
- 제품 컷은 배경을 지운 누끼 PNG를 권장합니다. 브랜드 공식 이미지는 사용 허락을 받은 경우에만 씁니다.
- 누끼는 rembg(`isnet-general-use` 모델)로 자동으로 딸 수 있습니다(무료, 로컬 실행). 캡처보다 원본 이미지를 쓰면 결과가 훨씬 선명합니다.
- 제품 이미지 출처 규칙: 제품명을 받으면 직접 검색해서 찾고, 누끼를 따서 씁니다.
  - 사용: 브랜드 협찬 제공 이미지, 브랜드 공식몰·홈페이지, 판매처 제품 상세페이지(올리브영·다이소몰 등)의 제품 컷
  - 사용 안 함: 다른 인플루언서·매거진·개인 계정이 찍은 사진, 모델 얼굴이 나온 화보컷
  - 가져온 이미지마다 출처 URL을 기록하고, 발행 전에 출처 목록을 사용자에게 보여줍니다.
- 누끼를 활용한 추가 양식 아이디어(요청이 오면 제작):
  - 제품 라인업: 모델 사진 아래에 제품 누끼 여러 개를 나란히 두고 제품명·컬러명 라벨을 붙이는 장
  - 발색 + 제품 콜라주: 발색 사진 위에 제품 누끼, 메이크업 컷, 설명 띠지를 겹쳐 배치하는 장

## 표지 배경 사진 (2026-10-01 결정: 세 가지 다 사용)
기본은 **풍경 배경 + 제품 누끼** 표지(`cover.style: "scene"`, `bg`·`image` 또는 `big`)입니다. 얼굴 없는 감성 사진을 흐리게 깔고 가운데에 누끼를 크게 올립니다.
**인물 사진 표지는 메이크업을 보여줘야 하는 레터에만** 씁니다: `letter.json`의 `cover.style`을 `"photo"`로 두고 `image`, `focus`(사진 위치), `credit`(출처 한 줄)을 넣습니다.
1. **AI 생성 (Topview)**: 인물이 나오는 일상 감성 컷. 1장에 약 0.3크레딧(Nano Banana 2 Lite, 1K, 4:5). **월 50크레딧 안에서만** 씁니다. **기본 세트(표지 1장+본문 일러스트, 위 "기본 제작 방식") 외에는 만들기 전에 반드시 사용자에게 먼저 허락을 받고**(무엇을 왜 만드는지, 예상 크레딧을 말한 뒤), **한 번에 1장만** 만들고(여분 생성 금지), 사용자가 보고 다시 요청할 때만 새로 만듭니다. AI 표기는 표지가 아니라 캡션에 한 줄로 넣습니다.
2. **무료 사진 (Pexels/Unsplash)** — 표지와 본문에 넣을 수 있는 무료 사진은 **먼저 찾아서 넣는다**(글자만 있는 표지·그림만 있는 본문으로 넘기지 않기, 2026-10-03).: 상업 사용 가능. 출처는 `sources.md`에 적습니다(표지에는 넣지 않음).
3. **핀터레스트**: 원작자를 찾을 수 있는 사진만, 배경으로만 씁니다. 연예인·셀럽 얼굴 금지. 표기는 `@pinterest`가 아니라 원작자 이름. 요청이 오면 바로 내립니다.
- 사진마다 `sources.md`에 출처 URL을 적습니다.

## 본문 장 배경 사진
- 배경을 넣을 때는 **사진 1장만** 씁니다. **콜라주는 절대 하지 않습니다** (2026-10-01 사용자 결정).
- `letter.json`의 슬라이드에 `"bg": "img/파일.jpg"`를 넣으면 연하게 깔립니다. 이미 만든 AI 이미지 중 안 쓴 컷을 재활용해도 됩니다.
- 표지처럼 사진을 진하게 쓰려면 `"dark": true`를 같이 넣습니다(배경만 표지처럼 블랙 그라데이션, 내용 배치는 그대로). 이때 하단 출처 줄(`foot`)은 빼고 출처는 캡션에 적습니다.
- 사용자가 고른 이미지가 있으면 그대로 쓰고, 새 이미지를 만들지 않습니다.
- 마지막 P.S. 장에는 표지 이미지를 연하게 다시 깔아 수미상관으로 마무리합니다(자동). P.S. 글자는 작게(110px) 씁니다.

## 광고 표시
협찬이나 광고 콘텐츠는 표지에 `#광고`를 넣고, P.S. 장 하단에 고지 문구를 넣습니다. 캡션 첫 줄에도 `#광고`를 씁니다.
협찬이 아닌 콘텐츠에서는 배지와 고지 문구를 둘 다 지웁니다.
