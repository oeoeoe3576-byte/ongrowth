# accommodation-reel-planning

숙소 릴스 제작의 기획 단계(가장 중요한 단계로 사용자가 직접 강조함). 사진을 고르고
영상을 만드는 건 그 다음 단계(accommodation-realistic-reels)이고, 이 스킬은 "어떤
숙소를, 어떤 말로 보여줄지"를 정하는 부분을 다룬다.

## 분석의 근거와 한계 (중요 — 반드시 읽을 것)

아래 규칙은 사용자가 보내준 5개 경쟁 계정의 **프로필 그리드 스크린샷**(썸네일 텍스트,
바이오, 팔로워 수)을 분석해서 뽑은 것이다. 유일하게 확보한 실제 성과(조회수) 데이터는
숙소도감(sookso.dogam) 계정에서 보인 2,267 / 6,989 / **52만** 세 개뿐이고, 그중
"산 하나를 통째로 앞에 둔 숲캉스 스파"가 압도적으로 터진 사례다. 그 외 계정들은
조회수/좋아요/저장 데이터 없이 썸네일 문구만으로 분석했다.

**즉 이 규칙은 "자주 보이는 패턴"이지 "확실하게 검증된 공식"은 아니다.** 사용자도
한 번 "제대로 분석한 거 맞냐"고 지적한 적이 있다 — 그 말이 맞다. 더 정확하게 하려면
조회수/좋아요가 높았던 게시물을 사용자가 추가로 더 알려줘야 한다. 그러니 이 스킬을
쓰다가 사용자가 추가로 성과 데이터나 영상을 주면, 그 내용으로 아래 규칙을 업데이트하고
"확실/추정" 표시를 구분해서 다시 정리해라. 모르면서 아는 척 단정하지 마라.

## 숙소 선정 기준

명확히 합의된 기준은 아직 없다 (사용자에게 가격대/지역/숙소유형/타겟층을 물어봤지만
"그게 아니라 계정 분석이 먼저"라는 피드백을 받고 분석으로 방향을 틀었음 — 아직
다시 안 돌아왔다). 숙소를 실제로 골라야 하는 상황이 오면, 아래 "헤드라인 규칙"에
잘 들어맞는 특징(독점적 시설, 반전 요소, 구체적 스펙)이 있는 숙소인지를 1차 기준으로
삼고, 가격대·지역·타겟층은 사용자에게 다시 물어봐라.

## 헤드라인(후킹 멘트) 작성 규칙

5개 계정(너드트립, 스테이브로, 허지니, 숙소도감, 체크인언니) 공통 패턴 + 52만 조회수
사례 가중치 반영:

1. **"반전/의외성" 프레이밍** — "~인 줄 알았는데 한국입니다", "몰디브 대신 여기..?"
   처럼, 보는 사람이 예상한 것과 다르다는 걸 먼저 던진다.
2. **가격 + 가성비 반전** — 구체적 가격("평일 5만원대", "단돈 만원")을 언급하고
   "이 가격에 이게 된다고?" 느낌을 세트로 붙인다.
3. **구체적 숫자/스펙** — "좋은 숙소" 같은 막연한 형용사 대신 "120년 한옥",
   "해발 765m", "400평 독채"처럼 숫자로 말한다.
4. **물음표·말줄임표로 궁금증 유발** — "~있다고?", "~인가요..?"
5. **독점성/배타성 키워드** — "통째로", "나만의", "독채" — 52만 조회수가 나온
   영상("산 하나를 통째로 앞에 둔 숲캉스 스파")의 핵심 요소였다. 이게 가장 강한
   신호이니 우선순위를 높게 둔다.
6. **그 시기 유행 키워드 올라타기** — 숲캉스, 촌캉스처럼 당시 화제가 되는 단어를
   붙인다. 지금 시점에 뭐가 유행인지는 WebSearch로 확인하고 지어내지 마라.
7. **헤드라인은 2줄을 넘기지 않는다** — accommodation-reel-captions 스킬의
   "중앙 자막은 반드시 한 줄" 규칙과 맞물린다. 컷마다 짧게 끊어서 쓴다.
8. **카테고리를 번갈아 쓴다** — 호텔/풀빌라/독채/글램핑/한옥/료칸감성 등 한 유형만
   계속 반복하지 않는다.

## 두 계정(스테이킴 / 어디감)과의 관계

이 스킬이 만드는 헤드라인·대본은 **두 계정 공통**이다 (영상·자막 내용이 같고
워터마크·음성만 다른 구조 — accommodation-reel-captions 참고). 계정별로 헤드라인을
따로 쓸 필요는 없다.
