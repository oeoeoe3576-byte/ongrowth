# accommodation-reel-captions

숙소 릴스 제작 파이프라인의 마지막 단계(자막 합성)를 위한 스킬. 앞 단계는
`accommodation-realistic-reels` 스킬(Topview로 사진 → 9:16 줌인 영상)이 담당하고,
이 스킬은 거기서 나온 "자막 없는 순수 영상"에 자막과 워터마크를 입히는 부분만 다룬다.

## 왜 이 스킬이 필요한가

Topview의 타임라인 편집 API는 텍스트 노드를 영상에 합성하는 기능을 지원하지 않는다
(`append_clip`에 텍스트 노드를 넣으면 "Timeline node type 'text' is not supported" 오류가
난다 — 실제로 확인된 제약이다). 그래서 자막은 Topview가 아니라 **CapCut에서** 입혀야 한다.

CapCut을 실제로 열고 조작하려면 Computer Use(화면 제어) 기능이 켜진 세션이어야 한다.
Claude Code처럼 화면 제어 도구가 없는 세션에서는 이 작업을 직접 수행할 수 없다 — 그런
경우에는 아래 "자막 스펙"만 표로 정리해서 사용자에게 전달하고, 실제 CapCut 작업은
Computer Use가 켜진 세션(Claude 데스크탑 앱 등)에서 이 스킬을 다시 불러와 진행하게 한다.

## 큰 그림

```
accommodation-realistic-reels 스킬이 만든 자막 없는 합본 영상(9:16, 여러 컷 이어붙임)
  → 컷마다 짧은 자막 문구로 분할
  → CapCut에 사용자 저장 프리셋([광고] 태그, @계정 워터마크, 폰트)을 불러와 이 스펙대로 배치
  → "스테이킴"(@stay__kim) 버전과 "어디감"(@eodigam_) 버전, 두 벌 내보내기
```

두 버전은 **영상 내용은 완전히 동일**하고, 아래만 다르다:
- 하단 계정 워터마크: `@stay__kim` vs `@eodigam_`
- 보이스오버 음성 (이 스킬의 범위 밖 — 음성은 별도로 합성/삽입된 상태라고 가정)

## 자막 스타일 스펙

실제 참고 영상 프레임을 분석해서 확정한 스펙이다. 추측이 아니라 관찰된 사실이므로,
사용자에게 다시 스타일을 묻지 말고 그대로 적용한다.

### 1. 우측 상단 — `[광고]` 태그
- 위치: 화면 우측 상단 모서리
- 색상/굵기: 흰색, 볼드
- 노출 시간: 영상 전체 구간 (컷이 바뀌어도 계속 떠 있음)

### 2. 중앙 자막 — 컷별 짧은 한 줄
- 폰트: 통통하고 동글동글한 굵은 한글 손글씨체(웹툰/배민체 느낌), 흰색 채움 + 검은색 외곽선(스트로크)
- 정렬: 가로 중앙 정렬
- 위치: 화면 세로 중앙 부근
- **반드시 한 줄**이어야 하고 좌우 끝이 잘리면 안 된다 — 그래서 문장을 길게 쓰지 말고
  짧게 끊어서 쓴다
- **컷마다 따로** 짧은 문구를 배정한다 (영상 전체에 긴 문장 하나를 깔지 않는다).
  예시 패턴: "호텔인데요" → "객실에서는" → "이런 게 있어요" 처럼, 한 컷에 한 조각씩
  이어지는 말투로 분할한다
- 사용자 드라이브에 이 폰트가 프리셋으로 저장되어 있다고 했으니, 직접 폰트를 고르지
  말고 저장된 프리셋을 불러와 쓴다

### 3. 계정 워터마크 — 화면 하단
- 텍스트: `@stay__kim` 또는 `@eodigam_` (버전에 따라)
- 색상: 흰색, 반투명
- 크기: 중앙 자막보다 작게
- 정렬: 가로 중앙 정렬
- 위치: 중앙 자막보다 아래, 화면 세로 기준 약 70~75% 지점 (하단에서 1/4 지점)
- 노출 시간: 영상 전체 구간

이것도 사용자 드라이브에 프리셋으로 저장되어 있으므로 그대로 불러와 쓴다.

## 실행 순서 (Computer Use 세션에서)

1. 사용자에게 받은(또는 이전 대화에서 전달받은) 자막 없는 합본 영상 파일을 확인한다.
2. 영상을 몇 개의 컷으로 나눠서 만들었는지, 각 컷이 몇 초인지 확인한다 (보통 2초 단위).
3. 그 컷 수에 맞춰 짧은 자막 문구를 컷 수만큼 나눠 쓴다 — 전체 스토리를 자연스럽게
   이어지는 말투로 쪼갠다. 대본이 이미 있으면 그걸 기준으로 쪼개고, 없으면 영상 내용을
   보고 짧게 새로 쓴다.
4. CapCut을 열고 영상을 불러온다.
5. 사용자 드라이브에 저장된 프리셋(폰트, `[광고]` 텍스트, `@계정` 워터마크)을 불러온다.
6. 위 스펙대로 배치: `[광고]`는 우측 상단 고정, 중앙 자막은 컷 타이밍에 맞춰 컷마다
   교체, 워터마크는 하단에 고정.
7. `@stay__kim` 버전과 `@eodigam_` 버전, 워터마크 텍스트만 바꿔서 두 번 내보내기한다.
   (영상 내용과 중앙 자막은 두 버전 동일)
8. 완성된 두 파일을 사용자에게 전달한다.

## Computer Use가 없는 세션에서 이 스킬이 트리거된 경우

CapCut을 직접 열 수 없으므로, 대신:
1. 위 "자막 스타일 스펙"을 표로 정리해서 사용자에게 보여준다.
2. 컷별로 나눈 자막 문구 초안을 함께 제시한다.
3. 자막 없는 영상 파일(또는 다운로드 링크)을 전달한다.
4. Computer Use가 켜진 세션(Claude 데스크탑 앱 등)에서 이 스킬을 다시 불러오면
   실제 CapCut 작업까지 이어서 할 수 있다고 안내한다.
