# 기획 v2 (2026-10-24) — 요즘어디감 영상

## 0. 왜 다시 짜나
- 1~2차 영상(15~20초, 날짜 3~4개)은 도달 ≈100, 평균 시청 2~3초, 저장·공유 0. 인스타가 100명에게 시험 노출한 뒤 멈춘 상태.
- 원인: ① 첫 1~2초에 볼 이유가 없음 ② 정보 밀도가 낮음(저장할 이유 없음) ③ 어중간한 길이 ④ 벤치마킹 없이 감으로 설계.
- 제약(사용자 지시): 자동화 계정, 직접 촬영 없음. 사진은 공식 출처(한국관광공사 포토코리아·업체 제공)만. 이모지·사람 얼굴 사진 쓰지 않음.

## 1. 데이터로 확인된 승리 공식 (유튜브 정보형 쇼츠 44,878편·채널 1,066개, 인스타 검증 전)
1. 제목/첫 화면이 **숫자로 시작** (점수 ×1.25, 상위10% 문턱 2배) — 비용·일정·N곳이 들어가면 추가 가산
2. **손실회피·기한** 훅: "이 날짜 아니면 헛걸음", "하면 안 되는 N가지", "10월 지나면 1년 기다려야"
3. **정보는 번호 목록**으로 (방곡방곡: 당일치기 6곳, 35~60초, 설명란에 1~6번 목록) — 저장 가치
4. 길이는 **6~9초 아니면 35~60초**. 15~20초 중간 길이는 상위에 거의 없음
5. 해시태그·이모지는 효과 없음, 요일·시각도 효과 없음
- 우리가 못 따라 하는 것: 9초 풍경 클립 계정(영상 소스 없음). 따라 할 수 있는 것: **번호 목록형·기한형·코스형** (정지 사진 + 글자로 충분).

## 2. 콘텐츠 3개 시리즈 (우리 자산으로 가능한 것만)
| 시리즈 | 훅 공식 | 영상 | 캡션 | 근거 자료 |
|---|---|---|---|---|
| ① 이번 주 마감 | "○/○ 끝나요, 안 가면 헛걸음" (기한) | 25~35초, 3~5곳, 곳마다 기간·장소 | 번호 목록 + 주소·운영시간·변동 안내 | 한국관광공사 행사 데이터(`festivals`) |
| ② ○○ 당일치기 N곳 | "주말 ○○, 이 순서로 6곳" (숫자) | 35~45초, 6곳 번호 목록 | 번호별 장소·한 줄 정보 | 공식 관광정보·업체 제공 사진 |
| ③ 요즘 새로 열었어요 | "이번 달 새로 열었어요 N곳" (신상) | 25~35초 | 개장일·위치·요금 | 신규 개장 보도·공식 안내 |
- 시즌 소재(단풍·온천·축제)는 ①②에 얹는다. 벚꽃·전시팝업은 데이터상 약함.

## 3. 영상 규격
- 0~1.5초: 숫자로 시작하는 한 줄 훅(큰 글씨 2줄). 정보 나열 전에 결론 먼저.
- 본문: 곳당 4~6초, 번호·곳 이름·시기/기한·한 줄 정보. 번호 목록이 화면에 항상 보임.
- 마지막 3초: "전체 목록은 캡션에" + 저장 유도(이모지 없이).
- 음악: 영상마다 다른 직접 제작곡, 약 −20 LUFS. 썸네일은 영상과 별도.
- 사실 확인: 공식·기관 출처만. 출처를 못 찾은 정보(소요 시간·주차·요금)는 넣지 않는다. "달라질 수 있어요" 안내 유지.

## 4. 검증 방식 (2주)
- 시리즈별 3편, 같은 요일·시간(18:30) 간격으로 발행, 같은 날 2편 이상 금지.
- 지표 3개: 평균 시청 비율(15초 영상은 6초 이상 유지), 저장 수, 공유 수. 도달 수는 100대면 "시험 노출 탈락"으로 본다.
- 판정: 시리즈 3편 평균이 기존 2편(2~3초)보다 나아지지 않으면 훅·구조를 바꾸고, 저장·공유가 한 번이라도 나오면 그 포맷을 늘린다.
- 유튜브 DB는 매일 갱신해 포맷 가설을 인스타 실제 지표와 대조한다.

## 5. 즉시 실행 순서
1. 시리즈 ①②③ 중 첫 3편(주제·구성안·시안)을 사용자가 컨펌
2. 사진은 포토코리아에서 사람이 안 나오는 것만 직접 선별
3. 영상·음악·캡션 제작 → 사용자 검토 → 승인 건만 18:30 예약
