# 레퍼런스 모음 (잘 먹히는 형태)

사용자가 직접 모아준 참고 게시물(@eat.eat.trip). 카드 시안을 만들 때 먼저 확인한다.
**더 잘 먹힌다고 사용자가 판단한 형태**이므로, 주제에 맞으면 이 틀을 우선 적용해 시안을 낸다.

| 파일 | 형태 | 핵심 |
|---|---|---|
| eateat-1-shopping-list-cover | 표지: 상품 컷아웃 콜라주 + 큰 흰 제목 | 어두운 배경 사진 위에 **실물 컷아웃을 흩뿌리고**, 하단에 굵은 2줄 제목 ("꼭 사야할 ○○ 리스트") |
| eateat-2-filming-spot-photo | 정보 장: 장소 전체 사진 + 작은 인셋 사진 | 큰 사진 한 장, 가운데에 **작은 인셋(관련 장면)**, 아래에 번호 · 장소명 · 한 줄 설명 2줄 |
| eateat-3-route-timeline | 코스 지도형: 세로 점선 타임라인 | 중앙 세로선 + 번호 점, **좌우 번갈아 사진 + 장소명**. 한눈에 동선이 보이는 요약 장 |
| eateat-4-food-photo-comment-cta | 맛집 장: 음식 사진 풀블리드 + 인셋 | 큰 음식 사진, 좌상단 작은 인셋, 하단에 가게명 + 한 줄 평 + **댓글 유도 띠** ("댓글로 ○○ 남기면 링크 공유") |
| eateat-5-itinerary-collage | 일정 소개: 사진 3~4컷 콜라주 + 큰 제목 | 좌 큰 사진 + 우 작은 사진 3장, 아래 큰 제목 + 설명 3줄(핵심 키워드만 빨강) |

## 우리 카드에 적용할 점
- **훅이 구체적**: "넷플릭스 시리즈 촬영지", "돈키호테 쇼핑 리스트", "MBTI J 90% 에디터가 정리한 2박 3일"처럼 **누가·어떤 맥락**인지가 제목에 있다 (단순 "○곳 모음"보다 강함)
- **사진이 크고 글이 적다**: 한 장에 정보 3줄 이내, 사진이 화면 70% 이상
- **인셋 사진**: 큰 사진 위에 작은 사진 한 장을 겹쳐 정보량을 늘린다 (장소 + 대표 메뉴/장면)
- **코스·동선 요약 장**: 마지막 정리 장을 번호 리스트 대신 세로 타임라인으로
- **댓글 유도(저장·공유 외 참여)**: 마지막 전 장에 "댓글로 ○○ 남기면 링크 보내드려요" 띠. 단, 실제로 보낼 수 있을 때만 쓴다
- 사진 출처 규칙(업체 제공만)과 출처는 캡션에만 적는 규칙은 그대로 유지. 레퍼런스의 드라마 캡처·타인 사진은 **형태만 참고하고 사진은 쓰지 않는다**
