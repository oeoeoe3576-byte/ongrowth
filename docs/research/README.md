# 여행 정보 유튜브 조사 DB

목적: 브이로그가 아닌 **정보성 여행 영상**에서 먹히는 길이·제목 구조·후킹·주제·구성(챕터)을 데이터로 확인하고, 계속 쌓아서 기획에 쓴다.

## 방식
- **공식 YouTube Data API v3만 사용** (유튜브 화면을 긁어 오지 않는다). 키는 환경변수 `YOUTUBE_API_KEY`로만 읽는다 (채팅·코드에 넣지 않는다)
- DB: `data/research/youtube_travel.db` (SQLite). 채널·영상·검색 기록·조회수 스냅샷(날짜별)을 쌓는다 → 시간에 따른 성장도 본다
- 수집: `python3 tools/research/yt_collect.py search → channels → videos` (중단 후 재실행하면 이어서 진행)
- 분석: `python3 tools/research/yt_analyze.py` → `docs/research/youtube-travel-report.md`
- 성적 점수 = 영상 조회수 ÷ 그 채널 영상 조회수 중앙값 (채널 크기 영향 제거)

## 할당량 (하루 무료 10,000 유닛)
- 검색 1회 = 100유닛, 채널·영상 조회 = 1유닛/50개. 채널 1,000개 모으는 데 검색 이틀 + 영상 수집 하루 정도

## 알 수 있는 것 / 없는 것
- 알 수 있음: 길이 분포, 제목 구조(숫자·질문·시기·비교 등), 제목 길이, 주제, 챕터 구성, 썸네일 주소, 시기별 성적
- 알 수 없음: 영상 안의 화면·자막·말, 시청 지속률(공개 데이터 아님), 썸네일 안의 글자 디자인(별도 이미지 분석 단계)

## 쌓이는 규칙
- 분석 결과 중 **반복해서 확인된 것**만 `docs/travel-workflow.md`의 기획 원칙에 옮긴다
