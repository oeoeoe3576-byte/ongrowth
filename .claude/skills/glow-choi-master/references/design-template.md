# 글로우 초이 블로그 디자인 템플릿

사용자가 원래 쓰던 '블로그 서식 복사함'(퍼스널컬러 시리즈) 디자인을 그대로 따른다.
2026-10-23에 만든 흰 배경 + 점선 프레임 템플릿은 반려됐으므로 쓰지 않는다.


## 1. 이미지 카드 (1000 × 1000, `tools/glowchoi/cards.py`)

| 카드 | 함수 | 구성 |
|---|---|---|
| **썸네일 1번** (2번과 글마다 번갈아) | `thumbs.podium` | 시상대(등수)형: 로지 베이지 그라데이션 배경 + 가운데가 높은 원기둥 받침대 3개 위 제품 + 위쪽 'GLOW CHOI BEAUTY NOTE' / Pretendard Black 제목 / 영문 이탤릭 / 모카 알약 부제 |
| **썸네일 2번** (1번과 글마다 번갈아) | `thumbs.label_photo` | 실사 배경(직접 찍은 사진 우선, 없으면 공식몰 제형 사진) + 로지 베이지 18% 톤 + 제품 라인업(접지 그림자) + 아래 가운데 2단 라벨(모카 박스 흰 글자 42px / 흰 박스 다크모카 큰 글자 96px) |
| 썸네일(예전) | `thumb` | 연한 배경 + 필기체 영문 + 굵은 한글 제목(Black Han Sans) + 포인트색 알약 부제 + 아래 빛나는 타원 위 제품 누끼 라인업 |
| 퍼스널컬러 표지 | `cover` | **퍼스널컬러 시리즈 전용.** 다른 주제 썸네일로 쓰지 않는다. 위아래 컬러칩 띠 7색 + 필기체 영문(Parisienne) + 아주 굵은 한글 제목(Black Han Sans, 진한 브라운) + 얇은 영문 부제 + 포인트색 한 줄 |
| 포인트 목록 | `point_list` | 컬러칩 띠 + 필기체 영문 + 굵은 제목 + 번호 동그라미 목록 (가장 긴 줄 기준 가운데 정렬) |
| 한눈에 보기 | `overview` | 연한 배경 + 흰 둥근 패널 + 항목명(포인트색) / 설명 / 해시태그 알약 |
| 제품 | `product` | 연한 배경 + 왼쪽 위 세로선과 '브랜드 / 제품명 / 카테고리' + 가운데 빛나는 흰 원 위 누끼 + 아래 굵은 #키워드 |
| 팔레트 | `palette` | 둥근 컬러칩 + 이름 + 색상코드 |

배경은 순백만 쓰지 않는다. 제품·한눈에 보기 카드는 테마의 연한 배경(tint)을 쓴다.

## 3. 이미지 구성 (검색형 기준 8장 안팎)

썸네일(1번 podium / 2번 label_photo 번갈아, `glowchoi_posts/thumbnail_log.md` 확인) → 체크 포인트 → 한눈에 보기 → 제품 카드 × 상품 수 → 루틴 포인트 → 선택 가이드(my pick).
직접 찍은 실사 사진이 있으면 제품 카드 앞뒤에 넣는다.

## 4. 본문 서식 (`tools/glowchoi/format_html.py`)

| 요소 | 서식 |
|---|---|
| 첫 줄(제목) | 가운데, 24px 굵게, 포인트색 |
| 본문 | 가운데, 15px, #333333 |
| 소제목([인용구]) | 왼쪽, 19px 굵게, #333333 |
| 강조([강조 박스], → 추천 줄) | 가운데, 나눔손글씨 펜 19px, 포인트색 |
| 제품명(01. …) | 굵게 + 포인트색 #번호 |
| 순서 목록(1. …) | ✅ + 굵게 |
| 단락 사이 | 빈 줄 `<p><br></p>` |

```
python3 tools/glowchoi/format_html.py 원고.md 이미지폴더 "#A07B5E" 출력.html
```
출력 페이지의 '전체 복사'를 눌러 네이버 글쓰기에 붙여넣는다.

## 5. 누끼

- 공식몰(Shopify `.json`) 제품 단독 사진을 rembg로 배경 제거한다.
- 세트 배너, 모델 사진, 다른 제품이 겹친 사진은 쓰지 않는다.
- 카드 문구는 원고 내용과 같아야 한다. 원고에 없는 효능·수치를 카드에만 쓰지 않는다.


## 6. 썸네일 색·형식 근거 (2026-10-24 분석)

- 대상: 뷰티·패션 키워드 1,500개 블로그 탭 1~5위 중 노출 횟수 상위 10% 블로그 453곳(전체 노출 자리의 35%)의 대표 썸네일 1,110장, 비교군 나머지 블로그 300장
- 형식: 거의 모두 실사. 글자를 넣은 썸네일은 약 1/4이며, 대부분 사진 아래쪽 굵은 글자나 색 라벨 박스
- 상위 10%가 더 많이 쓰는 색 (나머지 대비): 로지 베이지 #E1C4B4 1.53배, 누드 로즈 #D1A390 1.45배, 웜 그레이지 #DEDAD7 1.19배, 모카 #AE8977 1.17배
- 덜 쓰는 색: 순백 0.86배, 블랙 0.76배, 진한 브라운 0.78배, 블루 0.4~0.7배, 오렌지 0.45배
- 상위 10%가 더 밝고(밝기 0.67 vs 0.63) 따뜻한 색 비율이 높다(46% vs 37%)
- 사용자 결정(2026-10-24): 1번 시상대형(podium)과 2번 사진+라벨형(label_photo)을 글마다 번갈아 쓴다. 색은 둘 다 로지 베이지 + 모카. 배경 톤은 로지 베이지·웜 그레이지, 라벨은 모카, 제목 글자는 다크 모카 #483B33로 한다. 어두운 배경과 순백 배경은 쓰지 않는다.


## 7. 본문 카드 (`tools/glowchoi/body.py`, 2026-10-24 사용자 확정)

레이아웃은 한 가지(둥근 흰 카드, 가운데 정렬)로 통일하고, 썸네일 번호에 따라 색만 바꾼다.

| 세트 | 표지 | 본문 색 |
|---|---|---|
| A | 1번 시상대형 (`thumbs.podium`) | 로지 베이지 배경 + 모카 #AE8977 |
| B | 2번 사진+라벨형 (`thumbs.label_photo`) | 그레이지 배경(#F0EBE6→#DCD1C7, 표지 제형 사진 톤에서 추출) + 토프 #9C8574 |

정보 카드는 같은 글 안에서 모양이 겹치지 않게 서로 다른 구성을 쓴다.

| 카드 | 함수 | 구성 |
|---|---|---|
| 사기 전 체크 | `check_grid` | 2×2 체크 타일 (체크 아이콘, 01~04, 굵은 제목 + 설명) |
| 성분 비교 | `compare_columns` | 3열 비교표 (기호 원, 성분명, 이런 분께 / 알아둘 점) |
| 제품 | `product` | 위 NO·브랜드·제품명·성분 칸 묶음 + 아래 제품. A는 낮은 받침대 위, B는 받침대 없이 접지 그림자만 |
| 사용 루틴 | `steps_flow` | 아이콘 원(물방울·톡톡·해) 점선 연결 + STEP 알약 + 아래 강조 상자 |
| 선택 가이드 | `pick` | 고민 → 추천 제품 목록 + 오른쪽 작은 제품 사진 |
