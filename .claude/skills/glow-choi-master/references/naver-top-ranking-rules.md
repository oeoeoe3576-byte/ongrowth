# 네이버 블로그 상위노출 데이터 기반 작성 규칙 (뷰티·패션)

글로우 초이 글을 쓸 때 SKILL.md(PART 1~57)와 함께 적용한다.
SKILL.md와 충돌하면 SKILL.md의 고정 규칙(PART 57)이 우선이다.
아래 숫자는 모두 실제 수집 데이터에서 계산한 값이다.


## 0. 분석 개요

- 수집일: 2026-10-18
- 키워드: 네이버 자동완성으로 뷰티·패션 키워드 3,777개 수집 → 관련 없는 키워드 제외 → 1,500개 무작위 추출
  (뷰티 1,000 / 패션 500, 검색 결과가 비어 있던 2개 제외 시 1,498개)
- 상위노출 기준: 네이버 **블로그 탭 관련도순 1~5위**
- 분석 대상: 상위 1~5위 글 7,490건 (중복 제외 6,170개 글) 본문 전체
  + 비교용 6~10위 글 7,490건 (제목·발행일만)
- 원본 데이터: `naver-top-ranking-data.csv` (키워드별 1~10위 제목·발행일·URL)

### 한계

- 통합검색 첫 페이지(스마트블록·인기글)는 수집하지 않았다. 블로그 탭 기준이다.
- 검색량(월간 조회수)은 확인하지 못했다. 네이버 검색광고 키워드도구가 필요하다.
- 블로그 지수(C-Rank, 이웃 수, 운영 기간)는 측정하지 못했다. 상위 글의 22%는
  같은 키워드 묶음에서 5회 이상 상위에 오른 블로그(예: 한 블로그가 71개 자리) 글이었다.
- 상관관계이지 인과관계가 아니다. 1위와 5위의 차이가 작은 항목은 "필수"가 아니라 "기본값"으로만 쓴다.


## 1. 순위와 가장 강하게 연결된 3가지

| 항목 | 1위 | 5위 | 6~10위 |
|---|---|---|---|
| 발행 30일 이내 | **82%** | 64% | 57~61% |
| 제목에 검색어 단어가 모두 포함 | **72%** | 63% | 58~62% |
| 제목에 검색어가 띄어쓰기까지 그대로 | 40% | 33% | 28~31% |
| 태그에 검색어 포함 | **49%** | 40% | (본문 미수집) |
| 본문 첫 300자 안에 검색어 | 58% | 53% | (본문 미수집) |

나머지 본문 지표(글자 수, 사진 수, 소제목 수, 표, 쇼핑 카드 등)는
1위와 5위가 거의 같았다. 즉 상위권에 들어간 글은 형식이 비슷하고,
순위를 가르는 건 **최신성 + 제목 키워드 일치 + 태그**였다.


## 2. 최신성 규칙

- 상위 1~5위 글의 발행일 중앙값: **14일 전**
- 30일 이내 72%, 90일 이내 97%, 1년 넘은 글 1%
- 1위만 보면 30일 이내 82%

**규칙**

1. 같은 핵심 키워드는 **30일 주기로 새 글**을 검토한다. 90일이 지나면 거의 밀려난다고 본다.
2. 시즌 키워드(가을 메이크업, 겨울 코트 등)는 시즌 시작 2~4주 안에 발행한다.
3. 오래된 글을 고치는 것보다 새 각도(새 제품, 새 시즌, 새 비교 기준)로 새 글을 쓴다.
   (기존 글 수정이 순위에 주는 효과는 이번 데이터로 확인하지 못했다.)


## 3. 제목 규칙

### 수치

- 제목 길이: 중앙값 **37~38자** (중간 50%가 32~46자)
- 쉼표(,) 사용 33%, 숫자 39%, 괄호/대괄호 17%, 구분선(| ㅣ) 17%
- 물음표 12%, 느낌표 11%, 이모지 2%, 연도(2026) 3%
- 검색어 단어가 제목 앞 30% 안에 있는 비율은 27%로 낮다.
  → 맨 앞에 둘 필요는 없지만 **빠짐없이 들어가야** 한다.

### 검색어 의도 단어 따라가기

검색어에 아래 단어가 있으면 상위 제목도 같은 단어를 쓰는 비율:

| 검색어에 포함 | 상위 제목에도 포함 |
|---|---|
| 후기 | 93% |
| 코디 | 86% |
| 추천 | 81% |
| 비교 | 51% |
| 가격 / 차이 | 35% |
| 방법 | 23% |
| 순위 | 10% |

→ "추천·코디·후기"는 제목에 그대로 넣는다.
→ "방법·순위·가격·차이"는 그대로 넣기보다
  "바르는 법", "고르는 법", "TOP3", "N가지", "만원대"처럼 풀어 쓴 표현이 더 많았다.

### 상위 제목에 자주 나온 단어 (검색어 자체 제외)

후기 · 추천 · 내돈내산 · 가을 · 비교 · 올리브영 · 총정리 · N가지 · 추천템 · 가격 · 발색 ·
리뷰 · 솔직후기 · 코디 · 방법 · 사이즈 · 신상 · 다이소 · 쿨톤 · 웜톤 · 데일리 · 이유 ·
가성비 · 만원대 · 고르는 · 사용법 · 종류 · 모음 · 선물 · vs · TOP · 할인 · 세일 · 꿀팁

**글로우 초이 적용**

- 쓸 수 있는 단어: 추천, 비교, 총정리, N가지, 가을/겨울, 신상, 올리브영, 다이소, 쿨톤/웜톤,
  고르는 법, 사용법, 만원대, 가성비, TOP3, vs, 이유
- 실제 경험이 있을 때만: 후기, 내돈내산, 솔직후기, 발색, 써본, 리뷰
  (PART 10, PART 57-7 유지)
- 할인·세일·특가: 실제 행사 근거가 있을 때만 (PART 5 유지)

### 제목 공식 (데이터 기반 기본형)

```
[검색어 단어 전부] + [의도 단어] , [구체적 기준 또는 결과]
```

예: `건성 쿠션 추천, 화장 뜨는 이유부터 안 뜨게 바르는 법까지` (실제 1위 제목)
예: `여쿨 립 추천 3가지, 같은 로즈도 이렇게 다르게 골라요`

- 32~46자 안에서 쓴다.
- 쉼표 뒤 부제에 "무엇을 알려주는지"를 구체적으로 쓴다.
- 홈판형은 PART 6~7의 호기심형을 유지하되, 검색 유입도 노린다면 검색어 단어는 빠뜨리지 않는다.


## 4. 본문 분량 규칙

공백 제외 글자 수 기준:

| 구간 | 비율 |
|---|---|
| 1,000자 미만 | 17% |
| **1,000~2,000자** | **57%** |
| 2,000~3,000자 | 20% |
| 3,000자 이상 | 7% |

- 중앙값 **1,522자** (공백 포함 약 2,000자), 중간 50%는 1,136~2,028자
- 의도별 중앙값: 방법형 1,781자 / 비교형 1,753자 / 가격형 1,704자 / 추천형 1,561자 / 일반명사 1,482자

**규칙**

1. 검색형 기본 목표: 공백 제외 **1,200~2,200자**.
2. 방법·비교형은 1,500~2,500자까지 늘려도 된다.
3. 3,000자를 넘기는 글은 상위권에서 7%뿐이다. 길게 쓰는 게 유리하다는 근거는 없었다.
4. PART 25(분량을 먼저 맞추지 않는다)는 유지하고, 위 범위는 점검용 기준으로 쓴다.


## 5. 모바일 줄바꿈 규칙

- 줄당 평균 글자 수 중앙값 **20자** (중간 50%는 17~33자)
- 글 한 편 줄 수 중앙값 81줄

**규칙**: 한 줄 15~25자 안에서 끊는다. 2~4줄마다 빈 줄로 호흡을 준다 (PART 26 구체화).


## 6. 사진 규칙

- 사진 수 중앙값 **13장** (중간 50%는 8~19장)
- 0~4장 9% / 5~9장 23% / 10~19장 44% / 20장 이상 23%
- 글 1,000자당 약 9장
- 뷰티 12장, 패션 15장, 방법형 8장, 가격형 7장

**규칙**

1. 검색형 기본: **8~15장**. 패션 코디는 12~20장.
2. 방법형·가격 정리형은 5~10장으로 충분하다. 대신 표를 쓴다.
3. 홈판 쇼핑형(PART 33, 본문 3~5장 + 상품 카드)은 홈판 전용으로 유지한다.
   같은 글로 검색 유입까지 노리면 8장 이상으로 늘린다.
4. 사진 출처 규칙(PART 29~32)은 그대로 적용한다.


## 7. 소제목·구성 요소 규칙

상위 글에서 쓰인 비율:

| 요소 | 사용률 | 비고 |
|---|---|---|
| 인용구(소제목 역할) | **61%** | 쓰는 글은 평균 4개 |
| 구분선 | 45% | |
| 링크 카드(oglink) | 47% | 다른 글·쇼핑몰 연결 |
| 스티커 | 43% | |
| 이미지 슬라이드 | 41% | |
| 표 | 16% | 방법형 26%, 가격형 31%, 비교형 22% |
| 동영상 | 12% | |
| 요약/정리 문단 | 17% | 방법형 32%, 가격형 35% |
| 단점·주의점 | 16% | 비교형 36% |
| Q&A | 6% | 방법형 19% |

**규칙**

1. 소제목은 **인용구 3~5개**로 만든다. 소제목에 검색어를 꼭 넣을 필요는 없다
   (소제목에 검색어 포함 20%).
2. 표는 비교·방법·가격 글에만 넣는다.
3. 비교형에는 단점·주의점 구간을 넣는다 (PART 22 유지).
4. Q&A는 방법형에서만 검토한다 (PART 23 유지).
5. 스티커는 상위 글 43%가 쓰지만 순위와 관계가 없었다.
   글로우 초이 에디토리얼 톤(PART 39, 47)에 맞춰 쓰지 않아도 된다.


## 8. 키워드·형태소 규칙

| 항목 | 값 |
|---|---|
| 띄어쓰기 있는 검색어(예: 건성 쿠션 추천)를 본문에 그대로 쓴 횟수 | 중앙값 **0회** |
| 여러 단어 검색어에서 가장 적게 나온 단어의 횟수 | 중앙값 3회 (중간 50%는 1~6회) |
| 여러 단어 검색어의 단어별 횟수 (전체) | 중앙값 **7회** (중간 50%는 3~13회) |
| 가장 많이 나온 단어의 횟수 | 중앙값 **12회** (중간 50%는 7~21회) |
| 한 단어 검색어(예: 톤업크림)가 본문에 나온 횟수 | 중앙값 4회 (상위 25%는 11회 이상) |
| 본문 첫 300자 안에 검색어 단어 포함 | 55% (1위 58%) |
| 태그에 검색어 포함 | 43% (1위 49%) |

→ PART 11(완전일치 반복 금지, 형태소 분산)이 데이터로 확인됐다.

**규칙**

1. 띄어쓰기 있는 검색어는 통째로 반복하지 않고 단어를 나눠 쓴다.
   단어마다 역할이 달라 횟수도 다르다. '○○ △△ 추천' 형태 3단어 검색어 1,020편 기준 (2026-10-24 재계산):
   - 제품명 단어(예: 앰플, 쿠션, 틴트): 중앙값 **12회** (6~20회)
   - 수식 단어(예: 미백, 세미매트, 쿨톤): 중앙값 **6회** (3~12회)
   - '추천' 같은 의도 단어: 중앙값 **3회** (1~6회)
   - 본문 1,000자당 단어 평균 약 5.5회. 본문이 짧으면 비례해서 줄인다.
   (이전 판의 '각 단어 3~7회'는 가장 적게 나온 단어 기준을 잘못 옮긴 것이라 고쳤다.)
2. 한 단어 검색어는 **4~10회**.
3. 도입부 첫 300자 안에 검색어 단어를 모두 한 번씩 넣는다.
4. 작성 후 형태소 횟수는 실제로 센다 (PART 11, 57-10 유지).


## 9. 태그 규칙

- 태그 수 중앙값 **12개** (중간 50%는 8~18개), 태그 없는 글 6%
- 1위 글의 49%가 검색어를 태그에 넣었다 (5위 40%)

**규칙**

1. 태그 **10~15개**.
2. 첫 태그는 검색어를 붙여 쓴 형태로 넣는다 (예: `건성쿠션추천`).
3. 나머지는 서브 키워드, 브랜드명, 제품명, 피부 타입/퍼스널컬러 순으로 채운다.
4. 최종 출력에 태그 목록을 함께 제공한다.


## 10. 도입부 규칙

상위 글 첫 5줄:

- 인사("안녕하세요", "이웃님") 35%
- 고민·공감("요즘", "~때문에", "~하시죠") 30%
- 첫 5줄에 물음표 21%
- 결론 먼저 말하기 2%

**규칙**

1. 인사는 선택 사항이다. 글로우 초이는 인사 없이 바로 고민·공감으로 시작해도 된다.
2. 첫 3~5줄 안에 "누구의 어떤 고민인지"와 검색어 단어를 넣는다.
3. PART 12의 "결론 선공개"는 상위 글에서 드물었다(2%).
   검색형에서는 고민·공감 다음에 "오늘 정리할 내용"을 한두 줄로 알려주는 방식을 기본으로 한다.


## 11. 경험담과 순위

- 본문에 직접 사용 표현(내돈내산, 써봤, 발라봤 등)이 있는 글: 1위 37%, 5위 41%
- 제목에 후기·내돈내산·리뷰가 있는 글: 36%
- 키워드별 상위 5개 중 경험형 글이 4~5개인 키워드: 32% / 2~3개: 40% / 0~1개: 27%

→ 경험형 글이 순위에 유리하다는 근거는 없었다. 큐레이션·정보형 글도 충분히 상위에 있다.

**규칙**

1. 직접 써보지 않은 제품은 큐레이션형으로 쓴다 (PART 10 유지).
2. 키워드 검색 결과 상위 5개가 대부분 후기형이면, 그 키워드는
   (a) 실제 사용 경험을 확보한 뒤 쓰거나 (b) 비교·고르는 법 각도로 바꾼다.


## 12. 쇼핑커넥트 규칙

- 상위 글 중 쇼핑커넥트(브랜드커넥트·naver.me) 링크 또는 상품 카드가 있는 글: **12%**
- 상품 카드 사용: 1위 7%, 5위 4%
- 상품 카드를 쓴 글의 카드 수 중앙값 2개
- 카드 위치(글 전체를 5등분): 앞 20% 8% / 20~40% 16% / 40~60% 15% / 60~80% 20% / **마지막 20% 40%**
- 카드가 2개 이상인 글 102개 중 한 구간에 모은 글 25개, 나머지는 흩어 배치
  (위치 데이터는 186개 글 기준이라 표본이 작다)

**규칙**

1. 쇼핑커넥트를 넣어도 상위노출에 불리하다는 근거는 없었다. 1위 글 사용률이 더 높았다.
2. 카드는 글 후반부(마지막 40%)에 두는 것이 상위 글의 일반적인 배치다.
3. 상위 글은 여러 카드를 흩어 배치한 경우가 더 많았지만, 표본이 작고 순위와의 관계도 확인되지 않았다.
   글로우 초이는 PART 14·57-5의 "3개를 한 구간에 모은다"를 그대로 유지한다.
4. 상품 수는 1~3개 (PART 15 유지).
