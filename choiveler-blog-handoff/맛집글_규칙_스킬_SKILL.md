# 맛집 글 작성 순서

1. **경험부터 확인** – 방문 시간(점심/저녁), 함께 간 사람, 주문 메뉴, 맛·식감, 좋았던 점·아쉬운 점을 사용자에게 받는다. 받지 않은 경험·맛 표현은 지어내지 않는다. 다른 블로그 후기에서 가져온 내용은 "후기가 있다"로 표기한다.
2. **체험단 조건 확인** – 사용자가 준 화면에서 최소 글자 수, 사진 수, 필수 키워드(하나 선택), 공정위 배너, 매장 위치, 마감일을 정리한다. 체험단 최소 조건과 아래 규칙 중 더 큰 값을 따른다.
3. **매장 정보 조사** – 주소, 영업시간·브레이크·라스트오더, 주차, 전화, 가격을 확인하고, 확인 못 한 값은 사용자에게 확인 요청으로 남긴다.
4. 아래 규칙대로 원고 작성 → 6번 점검표로 숫자 확인 → 결과 보고.

## 1. 분량
- 본문 공백 포함 2,000~2,500자 (상위 글 중앙 2,066자, 보통 1,597~2,669자)
- 체험단 최소 조건(예: 1,300자)이 있어도 2,000자 이상을 목표로

## 2. 사진·영상
- 사진 20~35장 (중앙 25장, 보통 18~33장) · 글 약 80자당 사진 1장
- 사진은 연속 3~5장까지, 사이에 1~3줄 글
- 동영상 0~1개 (넣는 글 30%) – 국물·불판·조리 장면 등 움직임 있을 때만
- 지도 1개 필수 (95%가 넣음)

## 3. 글 구조 (순서)
1. 대표 사진 1~2장
2. 도입 2~4줄: 방문 계기·누구와·한 줄 요약 (인사말은 계정 규칙 따름. 상위 글 37%만 인사)
3. **매장 정보 묶음 — 글 앞 1/3 안에 (91%가 앞에 둠)**
   📍주소 / ⏰영업시간·브레이크·라스트오더 / 🅿️주차 / 📞전화 (+웨이팅·예약)
4. 지도 (정보 묶음 바로 아래. 상위 글은 앞 54% · 끝 45%)
5. 외관 → 내부·좌석 → 메뉴판·가격
6. 메뉴별 사진 + 맛 (가장 긴 부분)
7. 총평·추천 대상 → 마무리 (상위 글 43%가 "추천"으로 마무리)
- 소제목은 인용구 박스 2~6개 (69% 사용), 구분선 0~2개
- 꼭 언급: 주차(71%), 가격(56%), 웨이팅(37%)·예약(35%)은 해당 시

## 4. 키워드
- 제목: 검색어 반드시 포함 (100%), 검색어로 시작 (69%)
- 본문 지역어(공덕·송도 등) 12~16회 (중앙 11, 1~3위 13, 보통 7~18 · 1,000자당 약 5.5회)
- 본문 "맛집" 등 두 번째 단어 6~10회 (중앙 6, 보통 4~10 · 1,000자당 약 2.8회)
- 검색어를 띄어쓴 그대로 통째로: 1~2회 (중앙 0, 보통 0~2)
- 키워드는 문장 속에 자연스럽게 ("송도에 있는 칼국수 맛집") – 나열·반복 금지

## 5. 서식
- 가운데 정렬, 한 줄 평균 14자 안팎 (짧게 끊기)
- 굵게 5~15곳 (78% 사용, 중앙 8곳)
- 색 글씨는 포인트 몇 곳만 (49% 사용), 형광펜은 0~3곳 (32%만 사용)
- 큰 글씨·표는 거의 안 씀 (표 9%)
- 이모지 3~10개, ㅋㅋ·ㅎㅎ 0~3회

## 6. 제목
- 30~45자 (중앙 38자)
- 형식: [검색어] + 가게명 + 대표 메뉴/특징 (+ 주차·가격·웨이팅 같은 정보 단어)
  예: 송도 맛집 언양닭칼국수 들깨 닭칼국수 | 주차·웨이팅 정보
- 대괄호·세로줄은 선택 (27%), 앞에 계정용 표시 붙이지 않기

## 7. 기타
- 해시태그 선택 (49%), 넣으면 10개 안팎
- 체험단 글은 공정위 배너를 맨 위에 (텍스트 표기는 4%뿐, 대부분 이미지 배너)

## 한계
- 1~3위와 7~10위의 차이는 작았음 → 이 규칙은 "기본 조건". 순위는 블로그 지수(운영 기간·방문자 등) 영향이 커서 글 구조만으로 보장되지 않음
- 파워블로거·메이트·인플루언서 여부는 확인하지 않음 (검색 상위 노출로 대신 판단)

## 8. 자연스러운 키워드 넣기
- 검색어를 통째로 반복하지 말고 문장 속에 풀어서 쓴다.
  예: 키워드가 "인천 닭칼국수"면 → "인천에 있는 닭칼국수 집을 먹으러 갔어요"
- 같은 문장 모양으로 키워드를 반복하면 AI 글처럼 보이므로 위치·어미를 바꾼다.
- 키워드 개수만 채우려는 문장(근거 없는 경험, 억지 비교)은 넣지 않는다.

## 9. 작성 후 점검표 (보고에 포함)
- 글자 수(공백 포함/제외), 사진 자리 수
- 지역어·두 번째 단어·통째 검색어 횟수 (제목/본문 따로)
- 매장 정보 묶음이 앞 1/3 안에 있는지
- 24자 넘는 줄 없는지
- 사용자 경험이 아닌 문장(조사·다른 후기 기반) 목록

## 10. 원고 표기 형식 (자동 임시저장 도구용)
- [공정위] [대표] [소제목] [박스] [표] [지도] [마무리] [사진 NN - 장면 설명]
- {손:} 손글씨 · {굵:} 굵게 · {굵+색:} 굵게+포인트색
- 강조색·인사말은 계정 규칙(예: 초이블러 학습노트)을 따른다.
