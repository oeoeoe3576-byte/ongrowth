# 부업 쇼츠 분석 (2026-10-23, 2차 갱신)

## 범위와 한계 (먼저 읽기)
- 대상: 유튜브 데이터 API로 모은 한국어 쇼츠 125개 중 부업 방법·후기·정보로 분류된 **65개** (`data/shorts-db/tags.csv`의 valid). 조회수 10만 이상.
- 자막은 확보하지 못했다 (유튜브가 서버 요청 차단). **제목·설명·태그·길이**만으로 규칙 태깅했다 → 영상 안의 말(구조·CTA)은 모른다.
- 조회수로 뽑았으므로 "잘된 것만 본" 표본이다 (같은 공식을 쓰고 안 된 영상은 없다). 규칙 태깅은 거칠다.
- 조회수 상위에는 스팸(수공예 모집 반복)·기업 광고가 많아 제외했다 (수집기에 규칙 반영).
- 영상 속 금액·수익 주장은 검증되지 않았다. 우리는 수치를 단정하지 않는다.

## 요약 (65개)

- 훅 유형(중복 가능): 숫자·결과 20 · 반전·경고 17 · 방법·정보 13 · 인물·나이 13 · 질문 12 · 후기·체험 8

## 우리 영상에 적용할 규칙 (초안)
1. 길이 20~40초. 첫 문장(제목급)에 "누가/무엇을/결과" 중 둘 이상.
2. 훅은 **숫자·결과 / 반전·경고 / 질문** 중 하나. 단, **검증 안 되는 수익 수치는 쓰지 않는다**. 숫자는 방법의 수(3단계)·시간 같은 우리가 책임질 수 있는 것만.
3. 현실·경고형은 사실 확인된 것만 (예: 체험단 후기에 제공받았다는 표기). 근거 없는 겁주기 금지.
4. CTA는 강의·유료 유도 금지(사용자 지시). 저장·팔로우·다음 편 예고 정도. 상위 영상 다수가 CTA가 없으므로 억지로 넣지 않는다.
5. AI 인물이 "내가 직접 해봤다"는 개인 후기를 지어내지 않는다. 방법·정보 설명형으로 간다.
6. 자막은 필수 (화면 설명용). 썸네일/자막 디자인은 아직 분석 전.

## 썸네일·화면 구성 (조회수 상위 12개를 직접 보고 정리, 표본 12개)
- **상단 제목 자막이 거의 필수:** 12개 중 10개가 화면 위쪽에 큰 글씨 2줄을 얹었다. 1줄째는 흰색, **2줄째(핵심 구절)는 노랑 또는 분홍으로 강조**한 경우가 많다 (노랑 7개).
  - 예: "에어비앤비 운영하다 / **쫄딱 망해버렸죠**", "신문지로 일주일만에 / 100만원 버는 60대", "직장인 부업? / **정신 차리세요**"
- **하단 말 자막:** 12개 중 8개가 아래에 말하는 문장을 검은 상자 위 흰 글씨로 얹었다.
- **세로 9:16 안에서 위·아래에 글자, 가운데에 사진/영상**: 위 제목 / 가운데 피사체 / 아래 자막 구조.
- **가운데 피사체:** 돈 다발·실물 작업 장면·화면 녹화·사람이 카메라에 말하는 모습. 사람이 직접 말하는 영상은 4개 (방/책장 배경에 여성 크리에이터, 의자에 앉은 남성 등).
- **저작권 조심:** 상위 중 2개는 드라마·영화 장면을 썼다 → 우리는 쓰지 않는다.
- 이미지 파일은 저작권 때문에 저장소에 넣지 않았다 (분석 메모만 보관).

### 우리 영상과 비교
- 1편·2편에는 **상단 제목 자막이 없고** 하단 말 자막도 1편에는 없었다 → 상위 영상 공통 요소가 빠져 있었다.
- 우리 인물 설정(방, 책장, 앉아서 말하기)은 상위 사례(방 안 여성 크리에이터)와 비슷한 구도라 방향은 맞다.

### 적용 규칙 추가
7. 화면 위쪽에 **2줄 제목 자막**(1줄 흰색, 2줄 핵심 구절 노랑 강조), 아래에 말 자막.
8. 제목 자막은 영상 합성 도구가 필요하다 (현재 환경엔 없음). 해결 방법을 정해야 한다.

## 2차 갱신 (수집 확대 + 첫 화면 약 100개 직접 확인)
- 수집: 검색이 아니라 **채널 업로드 목록**(호출당 1유닛)으로 58개 채널의 영상 33,572개를 훑어 조건(10만 이상·180초 이하·주제어)에 맞는 후보 1,027개를 모았다 (`npm run shorts-channels`).
- 그러나 주제어만으로는 알바·배달 썰, 게임 뉴스, 공구 홍보가 많이 섞여서 **제목을 전부 읽고 분류**했다. 부업을 직접 다루는 영상(방법·수익·후기·플랫폼)은 **134개**. 1000개는 채우지 못했다 → 새 채널 발굴(검색)이 필요하고, 검색 한도 때문에 하루에 일부만 가능하다.
- 훅·CTA 통계(134개): 길이 중앙값 41초, 20~40초 41% · 훅: 숫자·결과 50, 방법·정보 34, 반전·경고 30, 질문 24, 인물·나이 19, 후기 13 · CTA 없음 80, 구독·링크 41, 강의·유료유도 22, 문의 18.
- 자막(대본)은 여전히 못 구해 **영상 안의 말(구조)은 분석하지 못했다**. 첫 화면(썸네일 1컷)과 제목·설명·길이만 근거다.

### 디자인 구조 (첫 화면 약 100개를 8열 격자로 직접 확인)
1. **검정(또는 단색) 바탕의 세로 레이아웃.** 영상이 화면을 꽉 채우는 경우는 드물다.
2. **위쪽 15~25% 구간에 2줄 제목**: 1줄 흰색, 2줄 핵심 구절만 노랑·분홍·초록·빨강으로 강조. 굵은 큰 글씨.
3. **가운데 28~65% 구간에 영상/이미지 창** (가로로 넓은 창).
4. 창 아래~65~78%에 **말 자막 1~2줄**(검은 상자 또는 외곽선), 일부는 맨 아래(85~90%)에 채널 이름·핸들.
5. 맨 위 약 10%와 맨 아래 약 20%는 비어 있다 → **플랫폼 UI에 가려지는 영역을 피하는 구조**다.
6. 화면 속 사람이 직접 말하는 영상, 돈·제품·화면 녹화가 많고 일러스트 채널은 거의 없다 (표본 편향 주의: 조회수 순).

### 안전 영역 (릴스, 제3자 자료 기준 — Meta 공식 확인은 못 함)
- 위 약 14%(상단 UI), 아래 약 35%(설명글·프로필·버튼), 양옆 약 6%는 글자를 두지 않는다. 우리 영상은 제목을 위 15% 아래, 자막 아래 끝을 아래에서 36.5% 위로 둔다 (`SAFE_TOP`/`SAFE_BOTTOM`).
- 이전 영상(1편, 2편 v1~v3)은 제목이 위 8%, 자막이 아래 13%에 있어서 **가려지는 영역**이었다 (사용자 지적).

### 우리 영상 규칙 추가
- 다음 편 예고에서 **"애드포스트"라는 말을 쓰지 않는다** ("글로 돈 버는 방법"까지만). 제목·자막·목소리 모두.
- 영상 형식(`navy` 테마): 남색 바탕 / 위 제목 2줄(흰색+노랑) / 가운데 크림 일러스트 카드 / 카드 위 남색 자막 상자.
